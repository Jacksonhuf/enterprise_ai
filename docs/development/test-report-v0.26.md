# 第二十六轮：个人界面密度

基线：PR #22已合并main，ff87b4c769ebca76bc69135b76e87fdd77732633。

## 行为

通用偏好的density使用既有GET/PUT settings/general和既有租户/用户隔离、版本保护，不新增HTTP接口。登录时读取当前用户的服务端偏好；成功保存后重新读取并应用。compact压缩导航、卡片、表格、表单与TDesign常规控件间距，comfortable及清空使用标准布局；正文大小、主题色与账户位置保持现行规范。样式仅作用于已登录app-shell，登录页不继承。

不把未保存表单输入应用到全局。偏好读取限定5秒，失败不阻断登录：首次使用标准布局，刷新失败保留此前已应用布局，通用偏好页显示错误并允许重试。账户代次、身份凭据、租户/用户及请求序号共同防止晚响应覆盖；退出立即清除偏好。语言和时区仍只保存，界面有明确说明。

## 验证

新增6项前端测试：登录恢复和清空、读取失败后重试、同账户退出重新登录的旧响应隔离、新旧请求交错、非法响应保留布局、登录偏好在途时退出。前端测试合计52项，本地全部通过；TypeScript、生产构建及体积预算通过，入口JS约247KB、总JS约726KB。

浏览器脚本新增真实表单选择紧凑并保存、刷新恢复、应用卡片计算样式18px、切换普通用户后标准布局24px。完整CI还会复跑95项Go测试、真实MySQL/PostgreSQL、API契约、四种存储运行验收和现有浏览器业务流程。最新CI结果记录在PR。

## 边界

当前仍是验证身份系统，不代替SSO。未实现跨标签页实时广播、全量国际化/时区格式化或全部Figma逐屏验收。本轮未修改数据库结构、A–E契约及生产部署。

首次浏览器运行发现定位器误用t-form-item；已依据实际TDesign组件修正为t-form__item，并同步修正紧凑表单样式选择器。修复后重新执行完整CI，最终结果以PR最新提交为准。
