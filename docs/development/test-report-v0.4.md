# 第四轮测试记录

日期：2026-11-15（中国标准时间）。范围为F/G应用、治理与原ReAct集成；A–E和模型服务测试仍使用独立HTTP夹具。

| 检查 | 结果 |
|---|---|
| Go测试及竞态 | 33项顶层测试通过，-race通过 |
| 内部HTTP契约 | 126组实际请求/响应通过v0.3检查 |
| 无效请求拒绝 | 其中2组故意不符合schema的请求返回400，错误响应也通过契约验证 |
| 前端测试 | 4项通过，含请求编号展示与不安全编号拒绝 |
| 前端类型/生产构建 | 通过；大分包告警仍存在 |

新增验证：

1. SQLite重开与新HTTP宿主下恢复已完成消息，不增加消息数、业务调用或用量。
2. 撤销服务授权后，历史消息、会话详情和重放不泄露旧结果；新的模型请求只得到脱敏历史。
3. 未完成消息不能重放为完成结果，未知权限配置版本的内容默认隐藏。
4. 浏览器伪造请求编号被替换，响应编号与异常记录一致；提供方密钥/私有诊断不进入错误正文。
5. 异常确认/解决/重开、并发版本冲突与跨企业拒绝均验证通过。
6. 授权变更及审计同次提交，避免重复审计；审计与用量不跨企业展示。
7. 审计和用量事件在SQLite重开后补投返回DUPLICATE，异载荷冲突不改写原记录。
8. 事件未知属性/缺失字段拒绝，规范uint64企业ID溢出及Unicode长度边界均覆盖。
