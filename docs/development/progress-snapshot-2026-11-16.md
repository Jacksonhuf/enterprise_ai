# F/G 完成度评估（2026-11-16，第三十八轮）

范围仅为 enterprise_ai 中用户负责的 F/G。PR #34 已合并 main，历史发布恢复为草稿已进入主分支；本轮服务输入/输出契约审阅随新 PR 交付。下列估计包含本轮改动，合并状态与最终 CI 证据见该 PR。旧进度快照保留历史含义。

## 当前判断

| 口径 | 工程估计 | 判断依据 |
|---|---|---|
| F/G 既定完整功能 | 约 65%–70% | 核心应用、运行、治理流程可验证，完整页面与深度配置仍有缺口 |
| 核心验证场景闭环 | 约 80% | SO1002 场景贯通前端、Go、独立 A–E HTTP Mock、鉴权、持久化和证据；正式联调尚缺 |
| 生产上线准备度 | 约 55% | MySQL 适配、审计迁移、恢复预检、隔离与回归增强；正式身份、关系表、可靠消息与负载验收未完成 |
| A–E 或整个平台 | 无可信百分比 | 未取得 A–E 当前开发和验收清单，不将 F/G 比例外推 |

这是依据当前代码、测试和已知缺项给出的区间估计，不是完整需求清单加权后的验收率。近期多轮存储改造主要提升稳定性，不能按 PR 数量或测试数量累加功能完成率。恢复草稿与本轮服务契约详情分别改善发布和引用流程；新增阅读界面不等于打通新服务，因此本轮不提高总体完成率区间。
