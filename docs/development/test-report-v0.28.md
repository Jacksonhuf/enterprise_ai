# 第二十八轮：MySQL审计迁移只读预检查

基线：PR #24已合并main，fad8003。

## 实现

编译命令cognara-migrate-audit新增--check，与--apply必须且只能选择一个。DSN继续来自环境变量；错误不输出DSN、事件正文或凭据。检查模式不建表、不播种、不执行FOR UPDATE、不修改状态或审计；采用ReadOnly/RepeatableRead事务，30秒总超时和既有连接I/O超时。

JSON报告包含source_schema_version、target_schema_version=2、audit_events、status和read_only=true。v1通过时READY，v2完整验证后ALREADY_APPLIED；任何失败非零退出且不返回成功报告。无源表、无单例状态、未知版本、不兼容目标或非空迁移目标均拒绝。v2逐行验证连续序号、租户/事件ID与payload一致及可识别时间，保留已接受的未知字段及大小写别名。不宣称验证完整业务关系或物理投影一致性。

v1检查与实际迁移共享源校验：64MiB状态上限、审计已知字段、合法事件身份/时间、租户内事件唯一。未知聚合字段保留；顶层非标准大小写Audit别名拒绝，因为实际迁移只应移除唯一明确的audit字段，否则可能切换后出现双份审计。不同租户可以复用事件ID，纳秒与MySQL日期范围之外的合法时间继续支持。

## 验证

新增5项顶层Go测试：纯源数据校验；真实MySQL空库/只读/实际迁移一致性及v2未知字段兼容；8类异常源或目标与失败保护；持有状态写锁时只读检查仍可完成；编译命令的标志互斥、JSON报告、无建表、实际迁移后复查和错误脱敏。Go测试总计100项。CI新增迁移命令编译并强制要求其测试入口，完整重跑竞态检测、真实数据库、接口契约、存储恢复及57项前端和浏览器回归。

本地数据库缺失时真实MySQL测试会跳过；正式结论以PR完整CI为准，不将本地跳过视为数据库通过。

## 运维顺序与边界

先在副本上运行--check，导出并验证快照及完整备份，执行恢复演练，再在受控窗口使用--apply；最后再次--check确认ALREADY_APPLIED。预检查只描述当前快照，不锁定后续数据，不证明未来迁移一定成功；--apply会重新校验并与写入竞争。实际迁移DDL可能独立提交并留下空表，本轮没有改变这一边界。

此项是生产数据迁移前的检查能力，不表示应用/消息/授权/用量等关系表、全局锁拆分、负载验收、SSO或A–E真实联调已完成。
