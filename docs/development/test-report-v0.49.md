# 第49轮：R05关系布局恢复检查点

基线PR45。新增内部恢复桥接器：在调用方一致性事务内从关系表原文独立重组，复用既有v2快照封装与审计读取，输出可由现有ImportMySQLSnapshot接收的检查点。不启用schema3、不新增公共导出或apply参数。

真实MySQL测试覆盖：关系原文与审计同快照封装、检查点state严格保留原文JSON数值表示及扩展、checksum导入独立空库、恢复后再次导出并核对state/审计、损坏投影与取消上下文均不返回成功检查点。源库聚合State与隔离关系布局不同，验证导出确实读取关系布局。

**兼容边界**：检查点文件保留原文数值字面值；现有v2导入器把state存入MySQL原生JSON，恢复时会按该类型归一化高精度数值。因此本测试对恢复库与MySQL归一化后的预期比较，不声称v2目标具有二进制原文的精度保真。未来正式schema3恢复需要直接恢复原文关系布局；本桥接不是该能力的替代品。

本地平台Go竞态通过，数据库专项因无DSN跳过；完整CI和真实数据库结果见关联PR最新head。R05仍开发中，生产根单权威、正式schema3读写/原投影/无损快照与apply切换尚待完成。
