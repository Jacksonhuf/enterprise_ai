# 第六轮：应用分页与发布配置复核

日期：2026-11-15。

## 本轮交付

- 应用列表复用既有query/cursor/next_cursor接口进行服务端搜索和追加分页；失败可重试，搜索竞态不会覆盖新结果，重叠页按应用ID去重。
- 发布历史支持追加分页；同一发布时间的记录以release_id作为稳定次序。列表显示真实发布标识，不再按当前页长度构造版本编号。
- 应用详情分别展示草稿和当前发布模型；模型目录加载失败时显示配置中的模型ID，不把未知模型伪装为验证运行。
- 只读抽屉支持所选发布对比当前草稿或当前发布，列出名称、描述、模型、提示词、资产、服务版本、受控能力、欢迎语及示例问题的变化。资产和工具集合忽略顺序，示例问题保留顺序，服务版本变化单独可见。
- 使用入口搜索仅依据已发布名称和描述，未发布草稿不再影响业务用户的搜索结果。管理入口继续搜索草稿。权限及既有API路径/字段保持不变。

## 验证与边界

新增前端5项测试，覆盖Vue响应式分页状态、搜索竞态、分页失败重试、重复请求/行去重、非前进游标、版本差异及配置不被修改。前端合计9项测试；类型检查、生产构建通过，仍有既有大包提示。

新增后端2项回归测试，覆盖已发布搜索与草稿搜索隔离、跨页完整性、相同时间发布排序、企业隔离及发布历史构建权限。Go顶层测试共43项，执行时使用真实PostgreSQL并启用race；132组内部HTTP契约校验，2个非法请求返回400。编译程序的JSON/SQLite/PostgreSQL正常退出、重启、消息重放与不重复计用量验收一并重跑。

复现：沿用make check-postgres、make verify-runtime、make verify-postgres；前端npm run test:cognara、vue-tsc及npm run build。

沿用既有TDesign、页面Tab、列表、按钮和只读抽屉，不引入新视觉主题。本轮没有完成浏览器逐屏/Figma视觉验收，不代表全量UI完成。游标仍为既有偏移分页：列表在分页期间新增/删除可能发生位移，客户端去重不构成一致性快照。没有新增回滚、撤回、自动发布或生产数据库迁移功能。
