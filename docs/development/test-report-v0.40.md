# 第四十轮：模板预览与版本保护（2026-11-17）

PR #36 已合并 main：a9bcd1326434808cfafd783da26af90b08d14429。本轮完善已有模板创建流程，复用Cognara/TDesign、完整选项加载器、配置投影及现有应用接口。

## 行为

- 现有应用来源独立于管理页搜索/当前页加载；完整目录有任一页失败时不交付部分列表。
- 选择来源后获取详情和草稿版本，预览模型、提示词、能力引用及对话默认配置；新应用名称和描述由表单提供。
- TEMPLATE新增可选expected_template_revision，新界面始终提交。服务端在同一创建事务内核对租户/版本并复制。旧客户端省略或null仍复制事务内最新草稿。
- 新应用不继承源应用的发布、会话和授权；版本冲突不创建应用，保留输入并要求显式刷新预览。
- 阻止重复提交，捕获提交表单与版本，关闭/导航后忽略迟到响应。网络、超时、5xx、无效成功响应后阻止重提/重新打开，需先刷新应用列表核对。接口无创建幂等键，该措施不构成跨请求精确一次保证。

## 回归

新增8项前端状态测试及3项Go HTTP测试。覆盖独立分页/失败、克隆、晚响应、版本冲突、重复/不确定提交、Unicode名称、创建字段、租户隔离、源配置不变、旧客户端兼容和错误码。

Chromium新增：管理页搜索无匹配 → 新建 → 从现有应用复制 → 独立目录选择/预览 → 检查POST携带版本 → 实际创建并进入编辑器 → 核对新草稿/独立身份/无发布/来源不变。

继续Go竞态、真实MySQL/PostgreSQL、内部契约、四种存储、恢复迁移、前端类型/构建/预算和已有浏览器业务回归。

## 证据口径与边界

本地执行环境不可用，不声明本地通过。平台顶层Go测试定义预计130项，前端预计84项；实际结果和提交SHA以本轮PR最新完整CI为准，最终证据记录在PR描述。

新字段为前端应用接口的兼容扩展，文档见fg-ae-contracts.md；不新增HTTP路由或A–E协议、数据库迁移。所有模板仍是当前同租户应用草稿，不构成独立模板发布市场。真实A–E、SSO、正式模型与完整页面视觉及生产验收仍待完成。
