# 第十七轮：MySQL初始化兼容检查

日期2026-11-16，基于PR #13已合并main（acc1be8）。

启动初始化在写入种子之前检查information_schema中的存储引擎和列定义。仅接受InnoDB、预期三个非空非生成列、id单列主键及JSON正文；存在额外列、非JSON列、不兼容主键或非InnoDB时明确要求显式迁移，不自动ALTER、删表或重置数据。额外状态行也拒绝接管。该检查不证明生产迁移/表结构已完成，也不验证任意DDL文本等价。

新增3项真实MySQL顶层测试：MyISAM/TEXT/无主键/额外必填列均拒绝且不写种子；异常ID行保留原记录；6个并发宿主初始化并写入后，重开仍保留数据，回调失败时修改回滚。当前适配已有未知schema版本拒绝；正式生产关系表和迁移工具仍待实现。

本地包测试通过但无MySQL实例，真实数据库执行以PR CI为准。完整CI继续覆盖MySQL/PostgreSQL、race、四种存储进程验收、前端、契约及浏览器回归。
