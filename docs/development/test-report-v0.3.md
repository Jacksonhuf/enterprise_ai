## 新增验证

- 资产发现同时按已发布引用和有效授权筛选，不把已授权但未引用的资产交给模型。
- 上下文响应不把context_receipt交给模型；身份/版本额外参数被拒绝。
- 未就绪或只读上下文不能执行，伪造、过期、不同用户/应用/发布/轮次的凭据均拒绝。
- 配置用途委托不能通过路由提示提升为执行用途。
- 正式指标执行、按同键重放、异载荷冲突，以及按客户端原始请求摘要恢复均验证通过。
- 仅有指标权限、没有服务调用权限的应用能完成原ReAct→正式指标→结果→证据链路。
- 撤销上下文授权后，新的指标调用及历史证据读取均被拒绝；读取过程中撤权不会输出专业内容。
- 上下文/服务工具共用调用预算；正式指标与服务使用现有v0.3路径及参数。
