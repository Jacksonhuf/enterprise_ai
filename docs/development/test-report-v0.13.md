# 第十三轮：对话历史管理

日期：2026-11-16。基于PR #8已合并的main（73ee9ac）。

## 交付

历史侧栏支持标题搜索、按最近活动排序、分页加载与显式刷新；元数据不加载消息正文。重命名使用当前会话版本，保留冲突输入，阻止重复提交与旧弹窗晚响应覆盖新会话弹窗。新建对话阻止重复点击。保存聊天后刷新侧栏，不重新挂载聊天页。

服务端在同一持久化事务内检查租户、所有者、应用授权及标题版本，写入新标题、随机版本、自定义标记与审计。首次聊天不会覆盖自定义标题，后续追加不改变标题版本。旧记录根据有效消息时间展示活动顺序，不编造创建日期。游标绑定可见列表快照，变化时明确要求刷新。

## 验证范围

新增3项Go测试：重命名/版本冲突/无变化/ABA/字符边界/所有者与租户隔离/聊天与重开持久化；45条旧数据跨页遍历、标题筛选、旧时间兼容、无消息正文与过期游标；两个真实PostgreSQL连接/API宿主并发重命名只有一方成功且只有一条成功审计，撤权后禁止修改和列表读取。

新增3项前端测试：Unicode标题验证、版本快照与重复提交抑制；冲突保留输入并要求重新打开；旧请求晚响应与新弹窗隔离。执行全部前端测试、类型检查与构建；Go race和真实PostgreSQL；内部HTTP契约回归；编译程序在JSON、SQLite、PostgreSQL下执行重命名、聊天、优雅重启、标题/版本保持、搜索与不重复计费用量的回放验收。

## 边界

列表默认由全量改为20条，需要按next_cursor取后续页。本轮不增加删除、归档、跨应用全局历史或消息正文搜索。并发列表变化需刷新，不承诺长寿命分页快照。仍为验证环境的聚合持久化模型；生产身份、真实A–E与模型联调及逐屏视觉验收未完成。

## 本地执行结果

69项Go顶层测试通过（含race和强制真实PostgreSQL），41项前端测试通过，Vue类型检查及生产构建通过。151对真实内部HTTP请求/响应通过v0.3契约校验，其中2项非法请求按预期400拒绝。JSON、SQLite、PostgreSQL三种编译程序验收全部通过，包含本轮新增的重命名持久化与重启后搜索。已有主包体积告警仍存在。
