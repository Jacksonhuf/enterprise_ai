## 实现

R05新增四表DDL、内部建表与严格结构校验；公共`--check`真实执行原始记录拆分、重组和JSON值对账，并新增`round_trip_verified`成功字段。不创建公共迁移入口，apply_supported仍为false，未SQL复制源数据、未开启schema3读写。内部DDL仅隔离数据库测试调用，DDL失败残留不自动删除。

原始记录保留根/应用头/配置/发布/检查扩展，发布数组顺序、null/空数组和checks缺失/null/对象形态；关联投影必须一致。json.Number避免float64舍入吞掉大整数、高精度值差异，键顺序/空白及等价字符串转义不作为差异，不宣称字节级不变。未来SQL复制仍须保存shape元数据及校验每个SQL列投影。

## 测试

新增7个平台顶层测试定义，平台现148项定义，新CLI既有2项。定义数不是验收比例。

- 纯记录对账：两版发布及顺序；多层未知扩展；大整数/小数；不修改源字节；null/[]及checks三种形态；伪造租户/对象/检查、重复记录、重复权威、丢检查/乱序发布拒绝或对账不等；非法JSON和相邻大整数不能被当成相等。
- CHECK规范化：接受MySQL标识引号/空白/外层括号/字符集前缀；保留字面量，不能吞掉字面量空格、括号、前缀片段或大小写变化。
- 真实MySQL：四表+最后当前发布外键建成后，DB与同一事务两种校验路径；大小写不同对象ID保留；跨租户草稿/发布指针、非对象配置、非法形态、删除当前发布受约束。
- 真实MySQL结构差异：缺表、额外/错误列或默认值、错误排序规则、缺外键或CASCADE替代、禁用/放宽CHECK、不可见/前缀索引拒绝；已有目标表不覆盖、不继续创建剩余表。编译后的CLI要求round_trip_verified=true。
