# 第十五轮：账户异步请求隔离

日期：2026-11-16。基于PR #10已合并main（9dcae13）。

登录初始化增加请求代次与凭据绑定。身份和运行配置均读取成功、仍属于当前登录请求时才一起发布到账户状态；初始化途中不展示可用角色。退出立即清空身份及模型状态，同时失效全部旧初始化/资料刷新。早先登录请求失败不会清除后来成功登录；同一账号退出再登录也不会被旧资料响应覆盖。

新增5项前端测试：退出时身份/运行响应在途、旧登录失败与新登录成功交错、运行配置失败不产生部分身份、同账号重新登录隔离旧资料刷新。扩展Chromium回归，在管理员页面访问后通过真实账户菜单退出，再以普通用户登录，检查管理员入口消失。API、服务端授权和验证身份机制未变，本轮不宣称生产SSO完成。

本地执行前端全部单元测试、类型检查、生产构建和体积预算；完整Go race、真实PostgreSQL、契约、三种存储和浏览器回归由PR CI验证。最终执行状态记录于PR。
