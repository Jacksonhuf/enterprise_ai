# 第十八轮：迁移前只读MySQL快照

日期2026-11-16，基于PR #14已合并main（632d39c）。

新增cognara-state-export命令，仅通过环境变量连接已有MySQL过渡状态库，不调用OpenMySQL，不创建表、不播种、不修改源记录。检查既有结构后，在只读REPEATABLE READ事务中读取schema_version=1的单行状态，拒绝未知版本、非对象正文和超过64MiB的快照。保留数据库返回的原JSON及未知字段，输出SHA-256、字节数和应用/会话/消息数量，不向标准输出打印内容或凭据。

文件以0600临时文件写完同步后，通过排他硬链接发布，已有路径（包括符号链接）不会被覆盖。父目录必须预先存在、支持硬链接；失败不发布部分文件。文件不包含独立封套，版本1的含义记录于本说明。SHA摘要用于完整性核对，不提供加密或来源签名；文件含业务数据，应按备份权限保管，禁止提交仓库。

新增3项顶层测试：真实MySQL快照摘要/数量/未知字段/权限/重复目标/符号链接拒绝；空库只读导出失败且不创建表和文件；独立文件发布不覆盖。增加编译命令验收，在CI已运行MySQL业务和重启验收后实际导出、核对摘要和权限并验证重复导出拒绝。

本地无MySQL实例，真实数据库与编译命令验收以PR CI为准。本工具仅覆盖当前聚合状态，不能替代生产物理备份、binlog/时间点恢复，也没有提供自动导入或生产表迁移。关系表设计与导入核对工具仍待完成，现有API不变。
