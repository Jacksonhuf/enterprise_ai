# 第51轮：R05-A schema3一致性读取器

基线PR48。新增内部schema3专用读取器，在调用方RepeatableRead及以上事务读取版本/唯一State根、重组关系原文并核对投影，按需读取独立审计。返回typed State及原始JSON，避免未来writer误用typed结果丢弃扩展。要求应用/会话容器有效、聚合审计为空；错误返回零State和nil原文。

真实MySQL专项在隔离fixture显式构造schema3并提交/重开：重组状态等价、审计可选、v2拒绝；普通OpenMySQL仍拒绝schema3，旧writer不调用业务回调；独立连接更新根后旧事务仍读原快照，新事务读新根；双权威损坏不返回成功原文。复用底层原文/结构/投影校验与已有损坏回归。
