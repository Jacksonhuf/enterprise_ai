# 第十九轮：空目标MySQL快照导入

日期2026-11-16，基于PR #15已合并main（8d73cdd）。

新增cognara-state-import命令，必须给出源文件、SHA-256和source-schema-version=1。读取上限64MiB，验证摘要、JSON对象结构、应用/会话/消息绑定，拒绝各层重复键、尾随JSON值和超过256层嵌套。摘要核对不是来源签名，操作员仍须信任源文件；不接收浏览器上传，不增加远程导入API。

所有源检查在连接目标库之前完成。目标库须预先创建；工具可创建兼容的空InnoDB过渡表，不播种。单行主键INSERT与事务提交仲裁并发导入，已存在状态（包括默认验证种子）均拒绝，不UPDATE、不清空；目标应用需停止后操作。DDL可能在后续失败时留下空表，不声称全程DDL回滚。提交结果未确认时要求检查目标，不自动重试。摘要和数量代表源文件；MySQL可规范化JSON格式，目标用逻辑内容核对，不保证原文件字节不变。

新增4项顶层测试：非法源/版本/摘要/重复键与绑定；真实MySQL导出→并发导入仅一方成功→重开→再次导出逻辑内容相同及覆盖拒绝；编译导入命令真实执行、结果报告与重复导入拒绝；摘要错误不在空目标创建表。CI先构建导入程序再执行测试，并保留原四种存储、导出命令、race、前端、契约和浏览器回归。

本地包测试通过，但无真实MySQL实例，数据库及编译命令实测以PR CI为准。该工具只迁移当前过渡聚合状态；未实现生产关系表拆分、在线增量迁移、生产跨服务/外部证据恢复。应在独立目标库核对、试运行后切换连接，保留原库；不自动切换应用或删除源数据。
