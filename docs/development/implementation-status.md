# 本轮实现与验收边界

## 已实现并自动验证

应用草稿独立保存；乐观锁；发布前解析资产当前版本、校验引用；发布检查绑定用户/草稿/有效期；发布快照不可变；同会话下一轮读取最新发布；进行中的轮次固定快照。

用户与应用身份分别授权；A–E通过真实HTTP回调Go校验签名委托、动作和华东验证范围。默认拒绝未授权的资源使用；不同企业、不同用户会话不可互读；服务授权撤销后下一轮被拒绝；输出前再次检查服务授权；前端身份注入字段不被接受。

实际调用链：Vue → Go /agent-chat → A–E Mock /service-executions → Go身份/授权回调 → 固定精度计算 → Go审计/用量事件回调 → 持久化消息 → SSE返回。证据读取再次检查会话归属与授权。Go存储为原子写JSON文件，失败更新不提交。

## 尚未完成

- WeKnora生产Agent/Session/工具注册接线、大模型解释与真实模型选择。
- 企业SSO、生产JWT/密钥轮换、生产身份提供方、数据库迁移和多副本事务。
- 模型/MCP/搜索/凭据/存储/队列等真实连接；这些配置页当前明确只读未连接。
- A–E真实联调、直接指标/规则执行（返回503）、真实取消、跨进程幂等/恢复保证、可靠事件发件箱。
- 全量页面清单中全部业务编辑器与深度配置的落地；本轮是核心应用/治理闭环。
- 原上游主服务完整编译、全量上游测试与生产部署。

Mock只支持SO1002、正式服务replenishment-gap v1.1及显式列出的资产。执行结果状态可成功或明确失败；未支持能力不会用虚构结果兜底。执行幂等仅存于Mock进程，重启后恢复返回UNKNOWN且safe_to_resubmit_same_key=false。审计与用量回调为本地验证投递，暂没有可靠发件箱。

SSE为本轮开发入口的消息协议；还不是对全部WeKnora原流事件的完整兼容实现。断流续接只重放已完成缓冲、不重新调用业务服务；服务重启后缓冲失效。停止接收不等于远端取消。
