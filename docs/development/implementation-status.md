# 本轮实现与验收边界

## 已实现并自动验证

应用草稿独立保存；乐观锁；发布前解析资产当前版本、校验引用；发布检查绑定用户/草稿/有效期；发布快照不可变；同会话下一轮读取最新发布；进行中的轮次固定快照。

用户与应用身份分别授权；A–E通过真实HTTP回调Go校验签名委托、动作和华东验证范围。默认拒绝未授权的资源使用；不同企业、不同用户会话不可互读；服务授权撤销后下一轮被拒绝；输出前再次检查服务授权；前端身份注入字段不被接受。

实际调用链：Vue → Go /agent-chat → A–E Mock /service-executions → Go身份/授权回调 → 固定精度计算 → Go审计/用量事件回调 → 持久化消息 → SSE返回。证据读取再次检查会话归属与授权。Go存储为原子写JSON文件，失败更新不提交。

## 新增接口（兼容扩展，原v0.3接口参数不变）

| 方法 | 路径 | 权限 | 参数/返回 |
|---|---|---|---|
| GET | /api/v1/cognitive/models | 构建角色 | items: id、name、credential_configured、status；不含密钥 |
| POST | /api/v1/cognitive/models/{id}/test | 管理员 | 路径id；成功status=VERIFIED；失败503；未知/缺凭据同样失败，不伪报连接成功 |

模型状态 VERIFIED 仅为本次进程内最近一次连通性测试结果，重启后回到 NOT_TESTED；不承诺实时可用。模型主配置由部署者维护，浏览器只选择与测试，不直接修改服务地址或提交秘密。

## 第三轮更新：资产工具及正式指标

四个受控工具现已按发布配置注册到原ReAct引擎。新增资产发现、专业上下文读取与正式缺口指标执行；只支持显式引用和授权的资源。指标执行要求读取上下文与执行两项独立权限，校验READY、上下文级别、版本、有效期与身份/应用/发布/轮次绑定。只读上下文不能用于执行，凭据不会提供给模型。

上下文、指标与服务使用的资源均在输出前重新鉴权，并在消息持久化事务内复核。正式指标证据根据已保存消息中的来源关联检查指标权限，已覆盖撤销上下文权限后拒绝读取证据；不依赖场景服务授权。

内部HTTP客户端增加可选`X-Invocation-Purpose`路由提示，用于区分资产发现/上下文的配置与运行用途。此提示不构成身份依据：Go仍验证已签名委托中的用途；执行、恢复、证据和取消等固定用途端点不接受该提示改变用途。

执行恢复使用已有v0.3 `DIRECT_EXECUTION`枚举。服务和指标请求统一按收到的JSON进行键排序规范化摘要，保留可选字段是否省略，避免服务端补默认值导致客户端无法恢复。Mock只提供进程内幂等，恢复仍不声称可安全重提。

第三轮完成后，仍需完成原生产Session整合、SSO、PostgreSQL、多节点能力、真实模型凭据与A–E实测、其他专业指标/规则适配及完整视觉验收。上文“直接指标未实现/其余受控工具未接入”只描述此前版本，现以本节为准。

## 第四轮更新：历史与运维可靠性

- 已完成消息的流重放从持久化记录重建，移除进程内流缓存依赖。正在执行或未完成的消息不能冒充完成结果重放。
- 新消息记录resource_uses与authorization_profile=1。历史读取、会话详情、重放及模型历史使用当前授权判断；撤权时返回脱敏占位，清除业务结果与证据入口。旧记录按执行来源及原发布保守判断，未知权限配置版本拒绝直接显示。
- 异常管理基于真实5xx记录，提供OPEN→ACKNOWLEDGED→RESOLVED及RESOLVED→OPEN状态迁移；预期版本不匹配返回409。已完成请求追踪编号与异常、HTTP失败审计的关联。
- 错误接口保持既有错误信封，只返回经过平台控制的信息，不透传提供方原始正文。内部可信服务的合法请求编号可沿用；浏览器不能指定服务端追踪编号。
- 授权新增/撤销、发布及异常处理状态与对应审计同事务提交。审计事件与用量的持久化去重已验证跨数据库重开补投，不重复入账。
- 内部审计/用量事件严格校验必填字段、未知属性、时间、长度、单位和规范uint64企业ID。新审计记录保留企业、资源、请求、应用及执行关联；审计和用量视图按企业隔离。

### 兼容接口补充

新增`POST /api/v1/cognitive/governance/exceptions/{id}/status`，仅管理员可访问本企业记录。请求为`{expected_revision: string, status: "ACKNOWLEDGED"|"RESOLVED"|"OPEN"}`，返回更新后的异常对象；非法状态400、版本冲突或非法迁移409、不可访问记录404。

消息响应新增可选字段：`resource_uses: [{type,id,action}]`、`authorization_profile: number`、`content_redacted: boolean`。原会话及重放路由与参数保持不变。脱敏消息不包含result、execution_id或资源消费列表；业务资源关联由服务端填写。

未承诺：进行中执行的跨进程恢复、A–E证据持久化及发送方发件箱、生产SSO/PostgreSQL/多节点、全量页面视觉验收。当前完成的是F/G接收与展示侧的可靠性验证。

## 第五轮更新：PostgreSQL 与运行验收
