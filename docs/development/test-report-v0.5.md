数据库用例覆盖：跨连接可见性、32次并发更新不丢失、回滚、锁等待取消后释放、并发启动迁移、未知版本拒绝及不重置、连接配置错误不泄露凭据。HTTP用例覆盖两个API宿主共享授权变更、重开连接后消息重放、用量事件补投去重。

编译程序验收覆盖：实际Go主程序启动并就绪、一次供应链业务调用、正常退出、同存储重启、已完成消息重放，以及重放前后用量不增加。检查进程存活与数据库就绪状态的区别：数据库关闭时/ready返回503，/health仍表示进程可响应。

## 重跑

```bash
make check-postgres
make verify-runtime
make verify-postgres
```

需要设置专用`COGNARA_TEST_POSTGRES_DSN`。未配置时普通`make check`会明确跳过真实PostgreSQL用例；`make check-postgres`和CI强制模式直接失败。CI使用独立PostgreSQL 15服务，继续执行前端测试、类型检查和生产构建。

## 验收边界

PostgreSQL当前为JSONB聚合验证适配，写入通过单状态行串行化，不代表最终生产表、索引、RLS、分库或高吞吐方案。尚未自动迁移JSON/SQLite数据；数据库初始化与身份仍为本地验证模式。真实数据库测试不等于SSO、真实A–E、商业模型、分布式部署或完整视觉验收完成。
