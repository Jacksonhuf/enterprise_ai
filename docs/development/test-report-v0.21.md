# 第二十一轮：MySQL审计按租户顺序分页

日期2026-11-16，基于PR #17已合并main（e05a168）。

MySQL v2审计列表不再先读取全部State.Audit。管理员权限检查后，在只读一致性事务中根据租户/事件定位旧游标，以sequence_no降序和范围条件按最多200条一批读取候选记录；筛选到limit+1条便返回。租户为空的历史记录继续按验证身份映射筛选，其他租户记录不参与候选读取。游标指纹和响应结构保持，v1及其他存储继续原路径。

提取并复用既有关键词/结果/时间筛选器，保证Unicode小写、子串、时区、纳秒和公元0001年等规则不被MySQL排序规则或DATETIME投影改变。筛选仍在Go中进行，稀疏匹配可能扫描当前租户很多记录，不宣称全文索引或所有筛选已下推SQL。数据库租户/顺序索引可用，但最终执行计划仍由MySQL优化器选择；本轮没有给出生产性能基准。

readiness的MySQL路径检查版本、聚合元数据和关系表结构，不扫描所有审计正文；返回的候选记录仍检查事件/租户关联及正序号。检查不等于全库数据完整性扫描。其他业务读取及更新仍重组完整审计，仍保留全局状态锁；仅审计列表避免该路径。

新增2项真实MySQL顶层测试：450条记录的v1/v2查询结果与游标一致、历史空租户归属、时间/关键词/结果组合、外租户隔离、权限拒绝及分页中追加不重复；430条跨批次稀疏命中与末页游标。完整CI保留race、四种存储、快照/迁移和前端/浏览器回归。真实数据库和最终结果以PR CI为准。
