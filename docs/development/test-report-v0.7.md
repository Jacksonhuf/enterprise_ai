# 第七轮：对话历史分页与授权复核

日期：2026-11-15。此轮从 main 的 0f11fa3 独立开发，不包含待合并的 PR #2。

## 交付内容

- 聊天页初始加载最近50条消息，提供刷新与加载较早消息；向前加载保留滚动位置。按服务端顺序展示，不用客户端时间重新排序。
- 新增可选 before_message_id 游标，指向当前会话已有消息，独占该消息之前的前缀。相同时间戳也可完整遍历；新消息追加不会进入此前游标范围。
- 旧 before_time 仍支持，改为按实际时间比较，正确处理时区偏移。两种游标不能同时提交；limit仅接受1–200。
- 会话目录读取复核当前应用使用权，撤销应用使用权后不能通过目录读取标题；会话与消息仍校验企业、所有者和应用权限。
- 每页继续应用既有资源撤权脱敏。前端遇到401/403/404时清空已显示的历史。刷新会先清空旧记录并重新鉴权；较早消息的普通网络失败可重试，旧请求不能覆盖刷新后的结果。
- 停止接收后尝试刷新已保存消息，不自动把原问题放回输入框；停止接收不代表远端业务取消。

## 兼容扩展

| 接口 | 新增/收紧参数 | 返回与行为 |
|---|---|---|
| GET /api/v1/messages/{session_id}/load | before_message_id可选，与before_time互斥；limit为1–200 | 保留success/data，增加has_more与next_before_message_id；结束时游标为null |
| GET /api/v1/sessions/{id} | include_messages=false可选 | 不包含消息内容，messages为null；默认仍返回按权限处理的历史 |
| GET /api/v1/sessions | app_id必填 | 无使用权403、其他企业应用404、缺参数400；成功结构不变 |

## 验证范围

新增3项Go回归，覆盖215条同时间戳历史跨页无丢失/重复、并发追加、会话元数据不加载全文、游标归属、边界/时区、跨企业/所有者拒绝、目录撤权和消息脱敏。main基线41项，本分支44项；不含PR #2新增的2项。

新增4项前端测试，覆盖Vue响应式状态、追加顺序、旧请求隔离、失败重试、撤权清空、并发加载与无效游标；本分支合计8项，不含PR #2新增的5项。完整检查沿用真实PostgreSQL、Go race、内部HTTP契约、三存储编译程序运行验收、前端类型检查/构建。具体执行结果见对应提交的CI记录。

## 尚未覆盖

本轮不提供远端取消、进行中任务跨进程恢复、历史删除/改名、会话目录分页或生产SSO。ID游标依赖消息只追加；未来若加入历史删除/重排，需要重新定义游标有效性。权限变化通过下一次请求检测，没有实时撤权推送；打开页面不等于实时授权订阅。

依然复用现有Vue/TDesign与Cognara主题；浏览器/Figma逐屏视觉验收未完成。生产数据库与真实A–E联调等原待办保持。
